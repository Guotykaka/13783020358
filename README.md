# 胡秀菊 · 月嫂个人主页

静态 H5 个人介绍页，展示月嫂资料、照护经历、技能与照片墙，支持电话联系与微信分享卡片。

线上地址：https://13783020358.pages.dev/

## 目录结构

```
├── index.html      # 页面与样式
├── assets/         # 头像、背景音乐等
├── imgs/           # 介绍视频与照片墙
├── .gitignore
└── README.md
```

## 本地预览

直接用浏览器打开 `index.html`，或任意静态服务器：

```bash
npx serve .
```

## 部署

推送到 Git 仓库后，由 Cloudflare Pages 自动发布到 `*.pages.dev`。

## 微信分享卡片

在 `index.html` 顶部的 `__SHARE__` 中配置：

| 字段        | 说明                                    |
| ----------- | --------------------------------------- |
| `siteUrl`   | 线上完整地址                            |
| `title`     | 分享标题                                |
| `desc`      | 分享描述                                |
| `imagePath` | 缩略图相对路径（当前为 `imgs/p13.jpg`） |

修改后重新部署。若微信仍显示旧内容，可在链接后加 `?v=2` 刷新缓存。

> 说明：`pages.dev` 为境外域名，部分环境下微信可能无法正常抓取卡片；如遇仅显示纯链接，可绑定国内可访问的自定义域名。
